# Blueprint Fitur: Analisis Kesehatan Lahan Geospatial-Based
> [!NOTE]
> Dokumen perencanaan konsep dan arsitektur untuk pengembangan modul **Kesehatan Lahan** berbasis data geospasial dan citra satelit pada dasbor Agrodemoplot v1.1.

Fitur **Kesehatan Lahan** dirancang untuk memberikan transparansi penuh kepada petani mengenai kondisi vegetasi dan hidrologi tanah mereka secara *real-time* memanfaatkan analisis indeks reflektansi citra satelit (seperti **Sentinel-2** atau **Landsat-8**) yang dipadukan dengan peta batas lahan (polygon demoplot).

---

## 🌟 1. Fitur Utama & Value Proposition

### A. Peta Indikator Geospatial Interaktif (Satellite Overlay)
Menyediakan modul peta interaktif (menggunakan Leaflet atau Mapbox) yang memetakan batas demoplot petani dengan pilihan layer filter indeks satelit:
* **NDVI (Normalized Difference Vegetation Index):** Mengukur tingkat kehijauan dan kerapatan kanopi tanaman (sehat, stres, atau tanah kosong).
* **NDWI (Normalized Difference Water Index):** Mengukur tingkat kandungan air pada tajuk tanaman dan kelembapan tanah permukaan (sangat penting untuk mendeteksi stres kekeringan).
* **SAVI (Soil Adjusted Vegetation Index):** Modifikasi NDVI yang sangat cocok untuk lahan bervegetasi jarang guna meminimalisir gangguan reflektansi tanah terbuka.

### B. Dasbor Metrik & Skor Kesehatan Lahan (Land Audit Card)
* **Skor Kesehatan Lahan (0-100):** Skor gabungan agregat kesehatan tanaman dan ketersediaan air tanah di demoplot tersebut.
* **Distribusi Kesehatan:** Grafik donat (*donut chart*) yang memperlihatkan persentase area lahan yang berkategori:
  * 🟢 **Sangat Sehat (Vigor Tinggi)**
  * 🟡 **Normal (Vigor Sedang)**
  * 🟠 **Stres Ringan (Vigor Rendah/Kekeringan)**
  * 🔴 **Lahan Terbuka/Kritis**

### C. Analisis Tren Historis (Temporal Analytics)
Grafik garis (*line chart*) interaktif yang memperlihatkan riwayat fluktuasi nilai rata-rata NDVI & NDWI kebun selama 6-12 bulan terakhir. Petani dapat membandingkan:
* Pengaruh musim kemarau/hujan terhadap kesuburan lahan.
* Dampak nyata sebelum dan sesudah dilakukannya pemupukan atau irigasi.

### D. Deteksi Anomali Spasial & Rekomendasi Cerdas (Smart Hotspots)
Sistem secara cerdas mendeteksi koordinat titik/zona di dalam demoplot yang mengalami penurunan indeks kesehatan secara mendadak (*hotspots*):
* *"Terdeteksi Anomali Reflektansi Rendah pada Zona Barat Lahan (Stres Air Tingkat Sedang). Rekomendasi: Lakukan pemeriksaan saluran irigasi sekunder di koordinat tersebut."*

## 📐 2. Rencana Arsitektur Database (Supabase Schema)

Untuk mendukung fitur ini secara efisien tanpa membebani server, kita dapat membuat tabel khusus di Supabase untuk menyimpan riwayat analisis bulanan hasil pemrosesan citra satelit:

```sql
-- Tabel untuk menyimpan riwayat analisis bulanan per demoplot
CREATE TABLE public.analisis_kesehatan_lahan (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  demoplot_id bigint REFERENCES public.demoplot(id) ON DELETE CASCADE,
  
  periode_analisis DATE NOT NULL, -- Bulan/Tahun audit, misal: '2026-05-01'
  skor_kesehatan INTEGER CHECK (skor_kesehatan BETWEEN 0 AND 100),
  
  -- Rata-rata indeks numerik
  avg_ndvi NUMERIC(4,3), -- rentang -1.000 s/d 1.000 (biasanya 0.1 s/d 0.8)
  avg_ndwi NUMERIC(4,3),
  
  -- Persentase klasifikasi area kebun
  pct_sehat NUMERIC(5,2),   -- persen area sehat
  pct_normal NUMERIC(5,2),  -- persen area sedang
  pct_stres NUMERIC(5,2),   -- persen area stres
  pct_terbuka NUMERIC(5,2), -- persen area tanah kosong
  
  -- Data GeoJSON untuk overlay peta resolusi tinggi (jika tidak menggunakan tile server)
  raster_overlay_url TEXT NULL, -- URL gambar heatmap NDVI transparansi 
  anomali_koordinat JSONB NULL,  -- Titik-titik hotspot bermasalah
  
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- Indeks performa query
CREATE INDEX idx_analisis_kesehatan_demoplot ON public.analisis_kesehatan_lahan(demoplot_id);
CREATE INDEX idx_analisis_kesehatan_periode ON public.analisis_kesehatan_lahan(periode_analisis);
```

## 🛠️ 4. Ide Alur Kerja Integrasi Data (*Integration Pipeline*)

Bagaimana data satelit masuk ke aplikasi?
1. **Pipeline Cloud Scheduler:** Script Python ringan di backend (atau Google Earth Engine / Sentinel Hub API) berjalan otomatis sebulan 2 kali saat satelit melintas bebas awan.
2. **Kalkulasi & Masking Lahan:** Citra dipotong (*clipped*) mengikuti koordinat polygon demoplot petani yang tersimpan di database Supabase.
3. **Penyimpanan di Supabase:** Rata-rata indeks dan URL gambar PNG transparansi hasil heatmap diunggah ke Supabase Storage, lalu datanya dicatat ke tabel `analisis_kesehatan_lahan`.
4. **SvelteKit Front-End:** Halaman `Kesehatan Lahan` mengambil data tersebut, merender peta Leaflet menggunakan gambar PNG heatmap tersebut sebagai `L.imageOverlay()`, dan menyusun grafik tren historis menggunakan Chart.js secara interaktif!
